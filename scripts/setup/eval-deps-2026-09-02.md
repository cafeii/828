# lzc-rnn 环境评估依赖安装留档（2026-09-02）

背景：三套下游评估（lm-eval 0.4.9 上游 / JRT fork / RULER）接入。为不扰动训练栈
（torch 2.9.0+cu128 / transformers 5.16.1 / fla 0.6.0 / flash_attn 2.8.3），
lm_eval 用 `--no-deps` 安装，其余均为版本无关的补充包。JRT fork 不安装，
经 PYTHONPATH 使用（与上游 lm_eval 同模块名，不能共存安装）。

执行记录（服务器 lzc-rnn，PIP_INDEX_URL=https://pypi.tuna.tsinghua.edu.cn/simple）：

```bash
pip install --no-deps lm_eval==0.4.9
pip install accelerate evaluate sqlitedict jsonlines pytablewriter numexpr \
    rouge_score sacrebleu word2number langdetect immutabledict zstandard \
    more_itertools tqdm-multiprocess tenacity jieba tiktoken pandas scikit-learn
pip install peft pybind11
```

实际新增（pip 输出）：lm_eval 0.4.9; accelerate 1.14.0, evaluate 0.4.6,
sqlitedict 2.1.0, jsonlines 4.0.0, pytablewriter 1.2.1(+DataProperty/mbstrdecoder/
pathvalidate/tabledata/tcolorpy/typepy/tabulate), numexpr 2.14.2, rouge_score 0.1.2,
sacrebleu 2.6.0, word2number 1.1, langdetect 1.0.9, immutabledict 4.3.1, zstandard
(已有), more_itertools 11.1.0, tqdm-multiprocess 0.0.11, tenacity(已有), jieba
0.42.1, tiktoken 0.14.0, pandas(已有), scikit-learn 1.9.0(+scipy/threadpoolctl/
joblib), peft 0.20.0, pybind11 3.1.0, 以及传递依赖 absl-py/chardet/colorama/lxml/
narwhals/portalocker/psutil/pytz 等。未触碰 torch/transformers/datasets/fla/triton/
lightning 版本。

已知兼容问题与对策：
- transformers 5.16 删除了 AutoModelForVision2Seq → lm_eval 0.4.9 models/__init__
  import 期崩溃；且 import evaluate 会替换 sys.modules["transformers"] 对象。
  对策：评估入口脚本先 import evaluate 再给新对象打占位 shim
  （scripts/eval/run_lm_eval.py、scripts/eval/run_jrt.py 头部）。
- JRT fork 的 based_lm/jrt_lm/local_lm 依赖 based/train/hydra → models/__init__.py
  已打 try/except 守卫（third_party/prefix-linear-attention/patches/PATCHES.md #2）。
