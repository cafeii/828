# 其他方向探索归档

本文件是非 QGDN 方向的唯一活跃归档。相关原型代码、临时作业记录和分散计划已经从
当前工作树移除；清理前的完整快照可在提交
`4e5330f0af2f4f730cfb990ada2a4bee98c66e3c` 中恢复。以下方向均未进入正式 FineWeb
对比，不能把原型验证或吞吐测试当作模型效果结论。

## LSA / GQA 状态压缩

这一方向把多个 query head 分组，共享较少的潜状态，并用静态投影恢复每个 head 的
value 表示。数学等价和接口原型已完成，但专用 GQA kernel 与正式质量实验没有完成。
它解决的是状态容量和服务效率问题，与 QGDN 的查询引导回忆问题不同。仓库仍保留
通用 GDN/GDN2/KDA 的 LSA 能力，已删除阶段性开发计划。

## DT-GDN

DT-GDN 尝试在同一步中联合满足 KV 写入目标和 query 回忆目标，并通过 2×2 闭式解
形成 rank-2 状态转移。关键问题是回忆目标若直接取当前状态在当前 query 上的读出，
其残差容易在所选展开点退化为零，目标也可能只是在约束状态复制。这个方向留下了
“联合目标必须提供独立训练信号”的教训，但没有形成可信的正式模型。

## JQC-GDN

JQC-GDN 先执行标准 GDN 写入，再对 query 访问到的旧内容做一次顺序巩固。它在巩固
门为零时精确退化为 GDN，因而适合做保守扩展；但第二次校正与现有状态更新高度耦合，
尚未证明能产生区别于调整遗忘率的有效信号。仅完成参考和并行化原型。

## QR-GDN

QR-GDN 为 `k→v` 和 `q→r` 分别维护同尺寸状态，总隐状态是 GDN 的两倍。它最清楚地
表达了“通过回忆形成新记忆”，也能测量两通道是否冗余。但它引入了明显的状态、显存和
带宽成本。最新原型在 340M、长度 4096 的单卡 H800 基准中只达到 GDN 约 72% 的吞吐，
未通过预设的 80% 正式训练门槛，因此没有提交完整训练。

## 单矩阵融合

把 KV 和 QR 更新直接加进同一状态，形式上会回到“对同一 fast-weight memory 做两次
rank-1 编辑”。如果没有独立目标、时间尺度或可识别的不变量，它与 QGDN/Q-Delta 类方法
难以形成清楚区别。后续若重启此方向，应先回答回忆写入保存了什么新增信息，再设计公式。

## 是否重启

只有在 QGDN 主线结论稳定后，才建议重新打开其中一个方向。重启时应新建独立分支和
实验目录，并先给出可证伪的假设、严格退化基线以及吞吐门槛，避免再次把多个原型混入
生产路径。
